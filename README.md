# Lepus Clicker

A browser idle/clicker game starring Lepus. Click the spinning Lepus, fill the fenced yard (it shows your wallet: 10 Lepuses merge into the next tier), and buy upgrades.

**Play:** https://jakezayak.github.io/lepus-clicker/

Run locally: `node tools/serve.js` (or `play.bat`), then open http://localhost:8642.
